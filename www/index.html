Engineering Pillars

Built with Pure Zsh Discipline

No Python, Node.js, or Rust harness dependencies. Pure Zsh 5.8+ leveraging native string expansions, standard CLI utilities, and subshell isolation.

Zero Compilation & < 1 ms Startup

Loads instantly in your shell without background daemon overhead. When sourced as a plugin, warm startup completes in under 1 millisecond.

Subshell-Isolated Coding Tools

Executes bash, read, write, and edit in isolated dedicated subshells. Temporary files are protected with zero-leak signal traps.

Dynamic Context Window Discovery

Auto-discovers Ollama model context limits dynamically via API queries and clamps token ceilings. Pluggable adapters for Anthropic, OpenAI, DeepSeek, and Gemini.

Multi-Tier Safety Guards

200-line output truncation with omission counters, 3-repetition infinite loop interceptor, hard step bounds, and optional --safe confirmation for file modifications.

ZLE Line-Editor Integration

Turn natural language thoughts into runnable shell commands directly on your prompt line. Press Ctrl+G and watch your buffer transform instantly.

Ripwire Complexity & CRAP Gate

Verified in CI against strict thresholds: Cognitive Complexity ≤ 30, Cyclomatic ≤ 25, and CRAP score ≤ 30 using Ripwire AST analysis.

Sandboxed Capabilities

Built-in Coding Tools

Every tool encapsulates its OpenAI function schema and execution logic under unified hooks with subshell isolation.

Tool Signature Isolation & Safety Description
bash command: string Subshell Fork Executes shell commands in a dedicated subshell, capturing combined stdout/stderr and return codes. Truncates output over 200 lines.
read path: string, start_line?: int, limit?: int Read-Only Reads file content with 1-based line numbers. Safely handles missing files, binary targets, and bounded ranges.
write path: string, content: string Atomic FS Creates or completely overwrites target files atomically. Automatically creates missing parent directories.
edit path: string, old_text: string, new_text: string Exact Match Performs surgical search-and-replace on existing files. Strictly verifies that old_text appears exactly once to prevent corruption.
