Core Workflows

Usage & Interaction

Operate zshai as an autonomous command-line agent, an interactive ZLE prompt widget, a multi-turn REPL, or a piped Unix pipeline filter.

CLI Execution

One-Shot Agent Tasks

Pass a natural language instruction directly to execute autonomous multi-step tool loops:

zshai "Fix failing test in spec/adapters_spec.sh"
zshai -m gpt-4o -s 10 "Refactor error handling in src/"
In-Shell ZLE

Line-Editor Widget (^G)

Type your natural intent directly at your Zsh prompt and press Ctrl+G to transform the buffer in place:

# 1. Type intent at prompt:
find all markdown files larger than 1MB
# 2. Press Ctrl+G (^G) — buffer transforms in place:
find . -name "*.md" -size +1M
Interactive

Multi-Turn REPL Shell

Launch an interactive session with full conversation memory, tool execution, and slash commands:

$ zshai
zshai> /model claude-3-7-sonnet-20250219
zshai> /thinking high
zshai> inspect package.json and summarize main dependencies
zshai> /exit
Unix Pipeline

Piped Standard Input

Pipe log files, git diffs, or compiler diagnostics directly into zshai as contextual input:

cat error.log | zshai "Diagnose the root cause of this failure"
git diff | zshai "Draft conventional commit message for these changes"

Sandboxed Capabilities

Built-in Coding Tools

Every tool encapsulates its OpenAI function schema and execution logic under unified hooks with subshell isolation.

Tool Signature Isolation & Safety Description
bash command: string Subshell Fork Executes shell commands in a dedicated subshell, capturing combined stdout/stderr and return codes. Truncates output over 200 lines.
read path: string, start_line?: int, limit?: int Read-Only Reads file content with 1-based line numbers. Safely handles missing files, binary targets, and bounded ranges.
write path: string, content: string Atomic FS Creates or completely overwrites target files atomically. Automatically creates missing parent directories.
edit path: string, old_text: string, new_text: string Exact Match Performs surgical search-and-replace on existing files. Strictly verifies that old_text appears exactly once to prevent corruption.
websearch query: string, limit?: int Read-Only Searches the web via DuckDuckGo Lite. Extracts page titles, direct URLs, and snippets without requiring external API keys.

Environment Variables & Settings

Configure model endpoints, safety controls, and reasoning budgets via standard environment variables or query dynamically with zshai config list.

Variable Fallback Default Description
ZSHAI_BASE_URL OPENAI_BASE_URL http://localhost:11434/v1 OpenAI-compatible API base URL
ZSHAI_API_KEY OPENAI_API_KEY ollama API authentication key
ZSHAI_MODEL OPENAI_MODEL qwen2.5-coder:7b Model identifier
ZSHAI_MAX_STEPS — 0 Maximum agent execution turns (0 = unlimited)
ZSHAI_MAX_TOKENS OPENAI_MAX_TOKENS 64000 Maximum generation tokens (clamped per model)
ZSHAI_NUM_CTX — auto Context window size (auto-discovered from Ollama)
ZSHAI_THINKING — off Reasoning budget (off, low, medium, high, or token N)
ZSHAI_STREAM — 1 Stream tokens live when in interactive terminal
ZSHAI_SAFE — 0 If 1, prompts before mutating tools
ZSHAI_TIMEOUT — 60 HTTP request timeout in seconds
ZSHAI_WEBSEARCH — 1 Enable web search tool (set 0 or use --no-websearch)
ZSHAI_ACTIVE_TOOLS — bash read write edit websearch Space-delimited active tools list
ZSHAI_RENDER — 1 Render markdown via glow or mdcat if installed
ZSHAI_BIND_DEFAULT — 0 If 1, forces binding ^G to widget
